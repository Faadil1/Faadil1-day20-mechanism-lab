# Blind Test Results

Store raw participant evidence here.

Rules:
- one file per participant;
- use the participant's own words wherever possible;
- never backfill a missing answer from interviewer interpretation;
- interviewer interpretation must be labeled separately;
- no participant-identifying personal data is required;
- participant IDs should be anonymous codes such as P01, P02, P03;
- do not upgrade a result from PARTIAL to PROVEN because it supports the preferred mechanism.

Use `RESULT-TEMPLATE.yaml`.

Initial balanced assignment is defined in `../ROUND-1-TEST-PACKET.md`.
