## Product premise

The system observes behavior and uses transparent deterministic rules to alter navigable terrain, but the user's actual intention is **UNKNOWN**.

Working creative law:
**YOUR BEHAVIOR BECAME TERRAIN. IT DID NOT BECOME TRUTH.**

Provisional mechanism name: THE BURIED PATH. Naming Lock remains BLOCKED.

## Experimental core

1. Show an original route to a stable Deep Time anchor, including distinct memorable landmarks.
2. Give the participant real, attractive, meaningful objects to inspect, revisit, ignore or keep. Do not demand meaningless clicks.
3. Observed interactions may change strata and route affordances under local inspectable model rules.
4. Ask the participant to return to the stable anchor. Their original route is no longer necessarily the simplest or most visible, but return remains possible.
5. The participant excavates actual historical layers: observed event → rule → before/after topology → navigational consequence.
6. Offer a real reversible choice to restore a route or keep the current navigational arrangement; log that as an explicit decision, not inferred intention.

## Key design challenge

The visual metaphor must be more than decorative geology:
- no arbitrary tectonic displacement without a logged rule;
- no guaranteed loss or artificially staged frustration in lieu of actual behavior;
- benefits and costs of curation must both remain possible;
- revealing causal provenance must not be a giant explanatory panel replacing interaction;
- Deep Time should anchor orientation; altered path, not landmark teleportation, carries the tension;
- historical cultural artifacts are contextual content sources, not proof the old web was intrinsically superior.

## Prebuild comparison / kill test

Build two deliberately lightweight, **functionally comparable** self-contained exploratory probes using the same small artifact corpus and real deterministic model:
A. STRATA / BURIED PATH — visibly accumulating layers that change a route and can be excavated.
B. ROUTE / UNRETRACEABLE CAUSE — route choice/retracing without geological styling, preserving the existing research comparison.

Participants should be able to use either probe without the thesis being disclosed. Before use, predeclare the observation and comprehension rubric, basic accessibility checks, negative/boundary scenario, and what counts as a meaningful user consequence.

Blind questions after the task:
- What changed in the environment?
- What do you believe caused that change?
- Did the system know why you acted, or did it use an imperfect signal?
- Did the change help or hinder you?
- Can you get back, understand the route, and restore an altered connection?
- Which parts are remembered or attributable after the reveal?

Acceptance is based on independently observable behavior and non-coached comprehension, not visual preference or a single positive reaction. Keep countercases where participants prefer the optimized route. Record where tests fail.

## Technical truth

Canonical model first:
`OBSERVATION → RULE → BEFORE STATE → MUTATION → AFTER STATE → RECEIPT`.

Represent edges, route costs, availability, reachability, strata, versions/snapshots and explicit decisions. Use a reversible deterministic implementation so replay matches actual recorded mutations.

WebGL is optional for the kill test. Prefer 2D/SVG/Canvas as **a working user-facing surface**, not a blank fallback. Production 3D/assets/sound are deferred until the mechanism survives.
