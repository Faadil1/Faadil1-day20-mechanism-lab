## Direction family hypotheses

### D1 — GRAVITATIONAL ATLAS
**Mechanism:** attention changes the terrain itself.

User begins in a navigable information landscape. Observed behavior creates attraction fields:
- revisited/engaged regions rise or move closer;
- ignored regions recede;
- paths bend;
- landmarks migrate.

Midway:
**FIND DEEP TIME AGAIN.**

Final reveal:
- MAP YOU ENTERED;
- MAP YOU LEFT;
- MAP THE SYSTEM BUILT AROUND YOUR BEHAVIOR.

Signature:
**ATTENTION HAS GRAVITY.**

Visual family:
editorial cartography + scientific terrain + restrained computational deformation.

Primary reference roles:
- San Rita: terrain as navigation, not visual identity.
- Cosmic Hunt: annotated map/constellation as narrative portal.
- D3-force: real physical layout dynamics.
- Three.js/R3F: spatial rendering.
- Motion: 2D text/UI transitions.

Collision guard:
do not copy San Rita's wilderness/vintage map identity or Cosmic Hunt's wolf constellation.

### D2 — VECTOR FIELD
**Mechanism:** each action bends the field through which later content travels.

The screen starts as clean trajectories/field lines.
Each observed signal alters local flow:
- paths curve;
- future nodes arrive along new trajectories;
- the user's next options physically emerge from the field.

Final replay overlays:
- actual action;
- system update;
- downstream bend.

Signature:
**YOU DIDN'T CHOOSE THE NEXT PATH. YOU BENT THE FIELD THAT PRODUCED IT.**

Primary reference roles:
- Google Land Lines: gesture-to-visual-world response.
- Three.js interactive lines: line-based GPU rendering.
- Motion: interruptible transitions.
- data-art/topographic line systems: material vocabulary only.

Collision guard:
avoid turning it into a decorative particle/line demo.

### D3 — SEDIMENT / EROSION
**Mechanism:** the model accumulates and removes information as geological strata.

Every interaction deposits, compresses or erodes layers.
The user navigates a cross-section rather than a graph.
Older assumptions remain visible as buried traces.
A small behavior can leave a large geological consequence.

Final reveal:
**THIS LAYER WAS BUILT FROM A PAUSE.**

Signature:
**YOUR BEHAVIOR BECAME TERRAIN.**

Primary reference roles:
- topographic/ridge-line data art;
- scientific cross-section diagrams;
- editorial typography.

Collision guard:
must remain an interactive causal system, not a beautiful static data poster.

### D4 — LIVING COMPENDIUM
**Mechanism:** ideas are living territories/orbs whose adjacency changes from inferred affinity.

The user travels between rich content bodies rather than nodes.
Connections reorganize; absent possibilities become visible in the final reveal.

Signature:
**EVERY GUIDE MAKES SOMETHING ELSE HARDER TO REACH.**

Primary reference roles:
- Planetary Compendium: living atlas / network-of-case-studies logic.
- Cosmic Hunt: spatial narrative indexing.
- editorial archive systems.

Collision guard:
avoid generic knowledge graph / bubble network.

      ↓
DETERMINISTIC MODEL
      ↓
D3 / custom force state
      ↓
R3F / Three.js spatial render
      ↓
Motion DOM overlay / typography
      ↓
SESSION REPLAY + CAUSAL REVEAL

- reduced motion keeps final spatial consequence but removes continuous deformation;
- essential task remains possible without WebGL.
