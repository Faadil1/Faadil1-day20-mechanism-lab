# Day 20 — Blind Comparative Test

Do not explain the thesis before a participant uses a probe.

## Opening
“Try this short interactive experiment. Use it however feels natural. I’ll ask a few questions afterward.”

## Questions
1. What do you think happened?
2. What did the system actually know about you?
3. What do you think it inferred?
4. Did anything change because of that inference?
5. What felt surprising, useful, uncomfortable, or unclear?
6. Describe the experiment in one sentence.

## Evaluate
- **Causal comprehension:** identifies behavior → inference → consequence.
- **Truth-boundary comprehension:** understands that true intention remained unknown.
- **Felt consequence:** a system decision altered something the participant cared about.
- **Explanation dependence:** thesis was or was not needed afterward.
- **Memorability:** participant can describe the mechanism in one sentence.
- **Collision warning:** participant calls it merely a feed simulator, algorithm dashboard, or old-web nostalgia piece.

## Promotion signal
Do not promote based on visual preference. A probe advances only if multiple participants independently identify the causal ambiguity without coaching.
